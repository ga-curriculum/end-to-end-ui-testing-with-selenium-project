## About

Build a simple full stack Python application with both a backend (FastAPI) and a static HTML frontend, and demonstrate your ability to write a complete and well-structured test suite that includes unit, integration, and end-to-end tests using `pytest` and `Selenium`.

Estimated completion time is around **15 hours**.

### Prerequisites

- Writing and running unit tests in Python using pytest
- Basic FastAPI routing and response handling
- Basic HTML structure and elements (e.g., forms, buttons, inputs)
- CSS selectors (IDs, classes, element types) for locating elements
- Installing and using selenium and webdriver-manager
- Launching a local web server with uvicorn
